# 编译环境构建与编译

宿主机存数据，Docker 容器做编译，宿主机只负责保存源码、接收产物。

宿主机 `docker/src/` 源码读写挂载，`docker/out/` 模拟器可写挂载

在 Docker 内部执行编译 —— `docker run` 启动编译容器，在容器内编译 Linux x64 版 Android Emulator，产物输出到宿主机 `out/emulator-dist/`

## 一、构建编译环境

前置条件：缓存 `ubuntu:22.04` 基础镜像。

```bash
docker build --network host -f Dockerfile.emu-build -t "$BUILD_IMG" \
    --build-arg "HTTP_PROXY=$PROXY_URL" \
    --build-arg "HTTPS_PROXY=$PROXY_URL" .
```

以已缓存的 `ubuntu:22.04` 为基础，构建编译镜像。

### 2. 构建内容说明

- `ARG HTTP_PROXY/HTTPS_PROXY` 由 `--build-arg` 注入代理
- apt 构建阶段走代理 `apt-get install git、build-essential、python3、python3-pip、ninja-build、ccache、cmake、curl、wget、unzip、rsync` 完整工具链与 emulator 编译依赖 `ca-certificates、libdrm-dev、libxkbcommon-dev、libgbm-dev、libasound-dev、libnss3、libxcursor1、libpulse-dev、libxshmfence-dev、xauth、pkg-config`
- `curl repo` 下载 repo 工具到 `/usr/local/bin/repo` 备用
- `ENV CCACHE_DIR=/ccache`、`USE_CCACHE=1`：`/ccache` 目录权限 777 供容器内 ccache/sccache 使用，配合 `-v` 挂载持久化；`WORKDIR /src` 容器工作目录

## 二、在 Docker 内部执行编译

前置条件：确保源码下载完整，在宿主机先切换到：

```bash
git -C external/qemu checkout 0739999921face0f42954f8edf001577471d9e75
```

源码校验：

```bash
git -C /data/user_home/predata/xgx/android_world/android_world-main/docker/src/external/qemu rev-parse HEAD
```

应输出 `0739999921face0f42954f8edf001577471d9e75`

### （1）启动容器命令步骤

1. **准备缓存目录 / 命名卷**

   使用宿主机目录挂载：

   ```bash
   mkdir -p "$CCACHE_DIR" "$PIP_CACHE_DIR"
   CACHE_MOUNTS=(-v "$CCACHE_DIR:/ccache" -v "$PIP_CACHE_DIR:/tmp/.cache/pip")
   ```

2. **源码校验**

   ```bash
   git -C "$SRC_DIR/external/qemu" rev-parse HEAD
   # 等于
   0739999921face0f42954f8edf001577471d9e75
   ```

3. **docker run 启动编译容器**

   ```bash
   docker run --rm -it --network host \
       -u "$(id -u):$(id -g)" \
       [--device /dev/kvm --group-add $KVM_GID] \
       -e HOME=/tmp -e XDG_CACHE_HOME=/tmp \
       -e EXPECTED_EMU_VERSION=34.2.15.0 -e EXPECTED_EMU_BUILD_ID=11906825 \
       -v "$SRC_DIR:/src" -v "$OUT_DIR:/out" \
       -v "$CCACHE_DIR:/ccache" -v "$PIP_CACHE_DIR:/tmp/.cache/pip" \
       -e PROXY_URL="$PROXY_URL" \
       "$BUILD_IMG" bash -c '<编译脚本>'
   ```

### （2）容器内执行的编译命令

1. **代理和 git 配置**

   ```bash
   export http_proxy=$PROXY_URL https_proxy=$PROXY_URL
   export HTTP_PROXY=$PROXY_URL HTTPS_PROXY=$PROXY_URL
   export GIT_SSL_NO_VERIFY=1
   git config --global http.proxy $PROXY_URL
   git config --global http.sslVerify false
   ```

2. **ctest 桩替换**

   跳过了 ctest 集成测试，避免测试因环境不完整而失败：

   ```bash
   mkdir -p /tmp/mock_bin
   echo '#!/usr/bin/env bash' > /tmp/mock_bin/ctest
   echo 'exit 0' >> /tmp/mock_bin/ctest
   chmod +x /tmp/mock_bin/ctest
   export PATH="/tmp/mock_bin:$PATH"
   ```

3. **编译**

   ```bash
   cd /src/external/qemu
   ./android/rebuild.sh --target linux --ccache auto --no-tests
   ```

4. **验证产物**

   ```bash
   if [ ! -f "objs/distribution/emulator/emulator" ]; then
       echo "FATAL: emulator binary not found"
       exit 1
   fi
   ```

5. **收集产物 -> /out/emulator-dist/**

   ```bash
   cp -a objs/. /out/emulator-dist/
   ```

6. **版本校验**

   ```bash
   emulator -version # 为 "Android emulator version 34.2.15.0"
   ```
